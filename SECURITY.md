# Security and sensitive-data reports

Please do not publish credentials, private keys, personal identifiers, private firmware dumps, or unredacted machine logs in a public issue.

For a security-sensitive report, use GitHub's **Report a vulnerability** feature for this repository when it is available. If private vulnerability reporting is not enabled, contact the maintainer through the GitHub profile to arrange a private report rather than posting exploit details publicly.

This project contains privileged low-level hardware code. Clearly state whether a finding was reproduced in a host simulation, an emulator/VM, or on physical hardware. Do not assume a simulator result proves behavior on real firmware or hardware.
